# Archived results

Each subdirectory corresponds to one self-contained numerical experiment. In most directories:

- `summary.json` records the parameters, diagnostics, and numerical claims used in the paper;
- CSV files provide tidy source tables;
- NPZ files retain dense numerical arrays or samples;
- PDF/SVG files are vector publication outputs;
- PNG files are convenient previews.

The two largest uncompressed TIFF exports were intentionally omitted because they duplicate the included PDF/SVG/PNG figures and add approximately 83 MB without adding source data. They can be regenerated by `scripts/run_robust_c_optimal_design.py`.

The main-paper provenance is summarized in `docs/FIGURE_MAP.md`. All author-generated content in this directory is licensed under CC BY 4.0 (`LICENSE-DATA`).
