# Data dictionary and provenance

## Data classes

All records in this repository are generated by theory calculations, exact probability enumeration, numerical optimization, or fixed-seed simulation. There are no experimental participants, personal data, confidential records, or third-party restricted datasets.

| Format | Meaning | Typical contents |
|---|---|---|
| `summary.json` | Human- and machine-readable final claims | Parameters, fitted exponents, information values, coverage, allocations, diagnostics |
| `*.csv` | Tidy source tables | Parameter grids, risks, estimator ensembles, figure coordinates, coverage summaries |
| `*.npz` | Compressed numerical arrays | Posterior samples, MLE ensembles, probability grids, bootstrap or simulation arrays |
| `validation_shard_*.json` | Independently generated grid shards | Fixed-seed bounded-MLE results for a half-open range of grid indices |
| `grid_shard_*.json` | Parameter-grid inference shards | Coverage and convergence results for one subset of the 81-point grid |
| `*.pdf`, `*.svg`, `*.png` | Rendered figures | Publication vector figures and preview raster images |

## Parameter conventions

| Symbol/name | Definition | Unit/domain in the manuscript |
|---|---|---|
| `T`, `temperature` | Bath temperature | Energy units with `k_B = 1`; design grid `{0.6, 0.9, 1.3}` |
| `mu`, `memory_angle` | Environmental memory collision angle | Radians; design grid `{0.2, 0.5, 0.9}` |
| `alpha`, `false_positive` | `P(Y=1 | X=0)` | Probability; design grid `{0.005, 0.02, 0.06}` |
| `beta`, `false_negative` | `P(Y=0 | X=1)` | Probability; design grid `{0.01, 0.04, 0.12}` |
| `e(T)` | Thermal excitation probability | `1 / (1 + exp(omega/T))` |
| `kappa` | Observable detector-temperature combination | `(1 - alpha - beta) e(T)` |
| `N`, `record_length` | Binary outcomes in one sensing trajectory | Main benchmarks use `N = 8` |
| `total_binary_readouts` | Common resource count | Sensing outcomes plus prepared-reference outcomes |

## Statistical units

- A sensing replicate is one independently prepared length-`N` trajectory. Outcomes inside a trajectory are correlated and are not treated as independent replicates.
- A ground- or excited-reference shot is one independent binary readout.
- The robust-design finite-sample archive contains 24 datasets per grid cell and 1,944 datasets per family/design over 81 cells.
- Random seeds are explicit in the corresponding scripts. No failed fit or boundary solution is silently removed from the archived ensembles.

## Missing values and exclusions

CSV files do not use a project-wide numeric missing-value code. Empty fields, where present, are descriptive values that are not defined for that row. The main validation archives retain nonconverged and boundary fits; consult the `converged`, `boundary`, and related diagnostic fields rather than filtering them implicitly.
